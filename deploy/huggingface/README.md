# notes-qa: live demo

Ask questions over PDFs and Markdown notes and get answers grounded in the documents, with citations back to the source file and page or section.

This demo comes loaded with a few sample notes (networking, databases, rate limiting). You can also upload your own PDF or Markdown files, up to 5 at a time and 10 MB each.

**Uploads are shared.** Everyone using this demo searches the same index, so don't upload anything private. To use your own notes privately, run notes-qa on your machine.

The demo runs in **Zero API Key mode**, which works offline and costs nothing. To get answers written by Google Gemini or Anthropic Claude, paste your own API key into the UI. It is used for that request only and never stored.

Source code and local setup: <https://github.com/Sege-Peter/Notes-QA>
